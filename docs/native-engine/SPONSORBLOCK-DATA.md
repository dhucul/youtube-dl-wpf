# SponsorBlock data attribution

Uses SponsorBlock data from https://sponsor.ajay.app.

The public API and database are offered under [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/), as described by the project's [official license page](https://github.com/ajayyy/SponsorBlock/wiki/Database-and-API-License). The settings feature tooltip includes the source and license attribution. Accepted interval data is cached only in the owned pending-download workspace; editing merges the selected intervals and projects chapters/captions onto the resulting media timeline. No segment submissions, votes or view reports are sent.

References: [official API](https://wiki.sponsor.ajay.app/w/API_Docs), [project attribution template](https://gist.github.com/ajayyy/4b27dfc66e33941a45aeaadccb51de71). Generated checks use invented interval data and isolated HTTP fixtures. Public removal remains unverified because the sampled long YouTube source requires an unresolved native playback challenge; see [batch evidence](EXEC-SPONSORBLOCK.md).
