## Scope

Build an independently implemented C# replacement for every currently supported yt-dlp site, retaining ffmpeg for media processing. Preserve the WPF app's queue, history, and supported download settings. No Python, yt-dlp executable, yt-dlp extraction code, or hidden fallback belongs in the replacement runtime.

The upstream catalog is frozen at the revision in `upstream-catalog.json`. Entries are extractor keys, not distinct website counts. An upstream entry marked broken still needs a documented decision; it does not count as implemented. Generic pages, embedded players, and additional upstream features must also be represented in the compatibility inventory.
