# Native JioSaavn subsets

Version 0.196.0 supports public song/episode URLs, albums, artists, featured playlists and numbered show seasons. These map to all six frozen JioSaavn keys, including the catalog's zero-width-space show-playlist spelling. They are implemented subsets, without full-parity claims.

The provider uses the website's observed `webapi.get`, `song.getDetails`, `show.getAllEpisodes` and `song.generateAuthToken` JSON contracts. It never reconstructs an audio URL from an obfuscated pointer or requests a DRM license. Selected canonical tokens, internal track IDs, collection IDs, artist ownership, endpoint identity, counts and cursor progress are checked. Album lists must be complete. Artist paging follows actual empty termination and refuses no-progress repeats, without mistaking short filtered pages for the end. Playlist `more_info.contents` provides authoritative ordered IDs; missing details are fetched in bounded batches and unavailable positions remain. A visible list count can differ from authoritative membership and is not used to discard inaccessible IDs.

Show bootstrap and dedicated episode-list APIs use different page sizes. Season inventory therefore uses the dedicated list from page one, with the publisher's count and duplicate/progress checks. Unplayable catalog rows with no duration remain unavailable, while selected playback requires a complete duration. Inventories contain metadata only; inspected selection revalidates membership and canonical archives, preserves inspected output indexes and obtains fresh normal playback.

Only issuer-returned clear media is offered. Service denials, preview descriptors and token-bound/protected playback remain unavailable. Normal clear HTTPS playback renews through the shared issuer session; complete local decoding and duration/size checks protect publication. Episode grants may use the specifically observed Spreaker download route and CDN, without allowing ordinary music grants to borrow that delegation. Root service credentials and signed resource fields are not invented or rewritten.

Public current-candidate observations include a five-track album, 787 playlist positions with 93 known unavailable rows, an 877-entry actor/artist inventory and a 910-episode season. Counts are observations of a changing public catalog, not fixed guarantees. The sampled music grant returned RightsError. A permitted public episode completed through the issuer-listed Spreaker URL, published and retained its full MP3, and repeated with no new callbacks; both files fully decode and their ordered coded audio packets match. See MUSIC-FAMILIES.md for exact evidence and limits.

Other URL/query shapes, other podcast hosts, account/subscription/region/proof/DRM contracts, lyrics, richer tagging and broader audio encodings remain pending. Real-account verification remains user-deferred. References are current first-party [JioSaavn pages](https://www.jiosaavn.com/) and the site's public client/API captures in `work/music-families-batch/reference/`; no third-party extractor code was used.
