# Native processing options and Whyp batch

Version 0.198.0 adds verified subsets for two previously globally refused classic settings and one missing provider family. The frozen catalog remains 1,731 keys, 126 classic settings and 276 long option names. Native production cutover remains blocked by the original full coverage requirement.

`PostProcess.Fixup` maps to explicit never, warn/detect_or_warn, detect_or_fix or force policy. Detection recognizes ADTS AAC or MPEG-TS mislabeled as MP4/M4A/MOV, and TS mislabeled as Matroska/WebM. Warning modes report the mismatch without modifying the source; never skips optional detection. Repair uses the detected input type and the existing metadata-preserving remux. Force remuxes even when no supported mismatch is detected. Blank retains the previous native behavior. Required timing/decoder correctness work in other native transports remains part of those transports; the policy does not disable their correctness checks. Stretched aspect, timestamp/duration/duplicate-chapter and other upstream optional repair detectors remain pending.

`PostProcess.PostprocessorArgs` maps to ordered typed `--postprocessor-args`/`--ppa` entries. Supported targets are ffmpeg, ExtractAudio, VideoConvertor, VideoRemuxer, Merger, Metadata, EmbedSubtitle, EmbedThumbnail and Fixup, optionally with `+ffmpeg`, `_i`, `_i1`/other actual input index, `_o` or `_o1`. Saved arguments precede job arguments. Input options go immediately before the matching input; output options go immediately before the owned output, after the engine's defaults. Multiple entries preserve order. A target runs only when its processing stage runs. Job-local scopes prevent concurrent jobs exchanging options, and probes/analysis/intermediate verification do not receive the overrides.

Supported output option/value pairs are metadata (global and stream selectors), movflags, ID3 versions, write_id3v1, compression_level, q:a/qscale:a, b:a, preset, crf, write_xing and threads. Input options are threads, thread_queue_size, probesize and analyzeduration. Quoting supports single/double quoted values and bounded escaped quotes/whitespace without a shell. Additional inputs/outputs, arbitrary filters/codecs/maps/protocols/external tools and unsupported grammar are refused. Existing stream/profile/metadata preservation verification remains authoritative; an override that breaks it fails before publication. Named input indexes absent from an actual invocation fail before launching FFmpeg for that stage. These are supported subsets, not arbitrary FFmpeg or full upstream option parity.

Saved settings, general extra arguments and job arguments retain their normal order and immutable capture. Analysis consumes and discards processing-only values without reinterpreting them as connection flags. Default request JSON, publication recipe and video/audio recovery identities match the preserved verified 0.196.0 binary. Explicit processing changes participate in publication recipes. No-overwrite/no-post-overwrite continue protecting final files; requesting retained originals can still require source transfer under existing policy.

The added Whyp provider supports current public IDs/slugs and numeric legacy track aliases. It validates API/canonical identity, full duration/size, public visibility and enabled downloads. Only issuer-offered HTTPS cdn.whyp.it MP3/FLAC resources are transferred. Audio version identifiers bind renewed formats; changed versions, removed permission, foreign resources, short media and cancellation fail without new archive/callback publication. Private/share-token/collection/other-version routes remain pending. See [Whyp](WHYP.md).

The new checks comprise 59 core, 19 media and five app cases. Two focused runs pass 57 processing and 35 Whyp checks (seven shared foundation checks occur in each). Thirteen retained generated workflows independently decode 37 files including sources, with 36 source/output stream comparisons: exact coded packets, canonical AAC after framing changes or decoded video pictures for TS-to-MP4. Two actual public Whyp workflows with force fixup and configured metadata independently decode four MP3/FLAC main/original files; both exact ordered audio inventories match, totaling 6,607 packets. Public archive repeats emit no new callbacks; public network/grant counts were not instrumented. Generated archive repeats perform no new media transfer/callbacks. All **4,129 native checks** (2,895 core + 1,234 media) and **160 app checks** pass on the frozen binary; Release has zero warnings/errors. The new batch adds 59 core, 19 media and five app checks. Default serialization/publication/recovery compatibility is verified against the preserved 0.196.0 binary. All 917 baseline working files remain accounted for; unchanged files and current source/document hashes are recorded in preservation.json.
