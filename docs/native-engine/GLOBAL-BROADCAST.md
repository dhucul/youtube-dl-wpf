## Captured dynamic DASH controls

--allow-dynamic-mpd and --no-ignore-dynamic-mpd enable the existing default; --ignore-dynamic-mpd and --no-allow-dynamic-mpd disable it. The last flag wins. WPF read-only analysis retains these discovery flags. Disabled dynamic MPDs are removed before format selection and publication, while static DASH and alternate HLS/progressive formats remain. The MPD type is read through bounded XML with DTD/external entities prohibited; malformed namespaces/types fail. A final downloader guard also refuses a presentation that becomes dynamic after initial filtering. Value-bearing flag syntax fails before discovery. Defaults make no additional requests and retain previous request serialization and recovery/publication identities.

These four names close captured argument-handler gaps. They do not close the three remaining classic global AdobePass fields: Auth.ApMso, Auth.ApUsername and Auth.ApPassword. Those still need a registered application/programmer context, real MVPD login, resource-bound entitlement and session renewal. Real-account verification remains user-deferred; no saved accounts are accessed. Source observations and frozen option/URL grammar are retained in work/global-broadcast-batch/reference; no upstream extraction implementation is used.
