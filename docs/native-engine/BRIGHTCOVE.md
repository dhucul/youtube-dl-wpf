The C# provider reads a player's public configuration and uses its policy only in the scoped Playback API request. It validates account and numeric/reference media identities, parses exposed clear progressive/HLS/DASH sources and captions, and converts API durations from milliseconds. Nonempty key-system descriptors are excluded from clear media candidates. Inline Brightcove video tags resolve through the same native player path.

Complete native playlist inventories retain per-entry media snapshots across validated paging. Incomplete or changed responses fail explicitly. Legacy/enhanced authorization and token provisioning, additional domain/geographic/collection/live and caption/codec metadata workflows, real account/remote renewal and full compatibility remain pending. The provider does not create credentials or call management APIs.
