# Native Whyp public track subset

Version 0.198.0 implements the frozen Whyp key for public tracks using the current first-party `/api/tracks/{public_id}` response. Numeric legacy `/tracks/{id}/slug`, current public IDs and slug/public-ID aliases bind canonical API, permalink, numeric archive and audio-version identity. Complete MP3 and FLAC are selected from literal issuer URLs; no signed address is reconstructed. Only HTTPS cdn.whyp.it resources are accepted. Shared job-owned clear authorization renews rejected/expiring grants and refuses a changed audio version.

The provider requires explicit public visibility and enabled downloads. Private, individual share links, disabled downloads and absent offered resources remain unavailable. Anonymous discovery/playback avoid sending account cookies or unrelated credentials. Full duration/size decoding verification precedes publication. Metadata, original retention, archive repeats, legacy routes, rejection and renewal are fixture/media verified. The website's own Example Track completes as both MP3 and FLAC with configured native processing; all four main/original files independently decode and both ordered coded-audio inventories match. No public private-account or forced renewal claim is made; forced renewal is controlled-test verified.

Collections, private/share-token and restricted embeds, explicit older versions, additional encodings/routes, account workflows and full upstream parity remain pending. Current first-party references: [Whyp features](https://whyp.it/features), [public example](https://whyp.it/tracks/example-track-HPuZgly3yViP), homepage client/public API captures in work/processing-options-batch/reference. Only page/client source text and public JSON were read; third-party extractor code was not used. See [processing batch evidence](PROCESSING-OPTIONS.md).
